# DR drill
Choose failure scenario/success criteria; confirm backup age/location; protect original system; record expected RPO/RTO; restore to isolated/approved target where possible; validate data and app connectivity; validate secret restoration without exposure; record actual recovery time/data-loss window; return intended topology; update runbook. A successful backup job alone is not a DR drill.
